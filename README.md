# LocaLink

Flutter + Firebase (auth, data, push, functions) + Supabase (file storage).

## Run
```
flutter pub get
flutter run --dart-define-from-file=env/dev.json
```
`env/dev.json` is NOT in Git. Copy `env/dev.example.json` to `env/dev.json` and ask A for the Supabase values.
